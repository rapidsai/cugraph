## Description: <br>
Accelerate existing graph analytics workflows with NVIDIA cuGraph and pylibcugraph, preserving graph semantics and validating GPU results; use for PageRank, traversal, community detection, centrality, similarity, and single- or multi-node GPU graph analytics, and route GNN training requests to the appropriate engine. <br>

This skill is ready for commercial/non-commercial use. <br>

NVIDIA <br>

## Use Case: <br>
Developers and engineers use this skill to migrate CPU or NetworkX graph analytics to explicit cuGraph/pylibcugraph GPU APIs, run single- or multi-GPU/multi-node analytics, maintain existing cuGraph Dask deployments, validate GPU results against CPU references, and route GNN training requests to Kumo Engine or cuGraph-PyG. <br>
